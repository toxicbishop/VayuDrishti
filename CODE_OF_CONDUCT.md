# Code of Conduct

## Our Commitment

VayuDrishti is committed to providing a welcoming, respectful, and constructive environment for everyone who contributes to the project.

Whether you are contributing code, research, documentation, ideas, bug reports, or feedback, everyone is expected to interact with others professionally and respectfully.

## Expected Behavior

Contributors are expected to:

- Be respectful and considerate toward others.
- Communicate clearly and constructively.
- Welcome different perspectives and approaches.
- Accept constructive criticism professionally.
- Focus discussions on the project and technical problems rather than individuals.
- Provide useful and respectful feedback.
- Give others an opportunity to explain their ideas and decisions.
- Respect the privacy of other contributors.
- Keep discussions relevant to VayuDrishti.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks.
- Threats, intimidation, or deliberate hostility.
- Discriminatory or hateful comments.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private or personal information without permission.
- Offensive or inappropriate language directed at other contributors.
- Deliberately submitting malicious code or changes.
- Repeatedly ignoring reasonable project guidelines.
- Any other behavior that would reasonably be considered inappropriate in a professional technical community.

## Contributions

All contributions are expected to meet the project's technical and community standards.

Project maintainers may request changes to, reject, or remove contributions that:

- Violate this Code of Conduct.
- Contain malicious or harmful content.
- Deliberately disrupt the project.
- Do not meet reasonable project requirements.
- Contain inappropriate or abusive material.

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it through the project's GitHub repository.

When reporting an issue, provide as much relevant information as possible, including:

- What happened
- When it happened
- Where it happened
- The GitHub issue, Pull Request, discussion, or other relevant location
- Any relevant screenshots or evidence

Reports will be handled as appropriately and privately as possible.

## Enforcement

Project maintainers are responsible for maintaining a respectful project environment.

Depending on the severity and circumstances of a violation, maintainers may:

- Ask the contributor to stop the behavior.
- Request changes to a contribution.
- Remove inappropriate content.
- Close an issue, discussion, or Pull Request.
- Temporarily restrict participation.
- Permanently restrict participation in the project.

Enforcement decisions will be made based on the circumstances of each individual case.

## Scope

This Code of Conduct applies to all VayuDrishti project spaces, including:

- GitHub repositories
- Issues
- Pull Requests
- Discussions
- Code reviews
- Project-related communication
- Other spaces where someone is representing the VayuDrishti project

## Final Note

The goal of this Code of Conduct is not to restrict technical discussion or disagreement.

Healthy technical debate is encouraged. Contributors may disagree about implementations, algorithms, research approaches, design decisions, or project direction.

The expectation is simply that disagreements remain **professional, constructive, and respectful**.

Thank you for helping make VayuDrishti a positive place to build, research, and collaborate.
